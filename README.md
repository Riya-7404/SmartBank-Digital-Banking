# 💳 SmartBank Digital Marketing Website

## 📖 Project Overview

SmartBank Digital Marketing Website is a responsive web application designed to promote SmartBank's banking services and digital campaigns. The project focuses on creating an attractive user interface that enhances customer engagement and provides information about banking products and services.

---

## 🚀 Features

- Responsive Landing Page
- Modern User Interface
- Banking Services Section
- Promotional Campaigns
- About Us Section
- Contact Form
- Mobile-Friendly Design
- Smooth Navigation
